# Менеджер задач

Выпускной проект представляет собой менеджер задач своего рода.
Позволяет создавать, редактировать, отмечать выполненными, удалять задачи уровня TODO, при этом есть возможность задать расписание конкретной задачи.

## Задачи со звездочкой

### Шаг 1
Реализована возможность задать TCP-порт, прослушиваемый сервером, через переменную окружения TODO_PORT.

### Шаг 2
Реализована возможность задать путь до файла с БД через переменную окружения TODO_DBFILE.

### Шаг 3
Реализована поддержка расписаний со спецификаторами w и m, создан обработчик запросов к api/nextdate.

### Шаг 4
Задачи со звездочкой отсутствуют.

### Шаг 5
Реализован поиск по тексту и дате задачи.

### Шаг 6
Задачи со звездочкой отсутствуют.

### Шаг 7
Задачи со звездочкой отсутствуют.

### Шаг 8
Выполнена парольная аутентификация, выдача и проверка токена. Пароль хранится открытым текстом (в промышленном проекте я бы использовал хэш bcrypt), пароли сравниваются как обычные строки (возможно тайминг-атака, в промышленном проекты я бы использовал сравнение с константным временем выполнения), нет поддержки отзыва токена/куки. Также в промышленном проекте передачу секрета для генерации токена я бы организовал с использованием кодирования в base64/hex.

Проект докеризован, используется двухэтапная сборка, размер результирующего образа в районе 14 мегабайт.

## Запуск проекта

### Переменные окружения

`TODO_PORT` - TCP-порт, который прослушивает сервер.
`TODO_DBFILE` - путь до файла с БД. Если файл не существует, он создается и инициализируется пустой таблицей с нужной схемой.
`TODO_PASSWORD` - пароль для аутентификации на главной странице. 
`TODO_TOKENSECRET` - секрет для генерации токенов. При его изменении все ранее полученные токены перестанут быть актуальными.
`TODO_MAXTASKS` - максимальное количество отображаемых задач.

### Локальный запуск

Все параметры конфигурации имеют рабочие значения по умолчанию. Запустить проект локально можно командой
```
go run main.go
```
Открыв в браузере http://localhost:7540, можно получить окошко для ввода пароля. Введя пароль по умолчанию `12345`, можно получить доступ ко всей функциональности проекта.

### Запуск тестов

Параметры конфигурации тестов имеют рабочие значения по умолчанию. Запустить тесты при запущенном локально сервере (см. предыдущий пункт) можно командой
```
go test -v -count=1 ./tests
```
из корня проекта.

### Запуск через докер

Образ собирается командой `docker build . -t taskman:v1`
Контейнер на основе образа запускается командой  `docker run -d -p 8080:7540 taskman:v1`
Открыв в браузере http://localhost:8080, можно получить окошко для ввода пароля. Введя пароль по умолчанию `12345`, можно получить доступ ко всей функциональности проекта.
Описанные выше переменные окружения актуальны и для случая запуска проект при помощи докера.
